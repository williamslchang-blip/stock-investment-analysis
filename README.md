# 全球股市分析以及個人投資分析專案

本專案用於追蹤與分析全球股市大盤、總體經濟指標、台灣與國際個人投資持股績效，並透過量化選股模型、當沖/日內對沖決策與盤中出場雷達機制尋求最佳投資組合配置。

## 專案目標

- **瞭解投資績效**：每日動態更新國內外持股最新市場收盤價，計算總資產、個股損益與年化報酬目標達成度。
- **尋求最佳投資組合**：結合學術因子模型（動量、52週高點、均線排列、相對強度、法人籌碼等）與季節性效應（同月份歷史漲幅），挑選具潛力的衛星觀察標的。
- **自動化研究報告產出**：每日定時自動抓取最新行情與重大財經新聞，繪製視覺化圖表與 Dashboard PDF 報告。
- **地端即時監控與當沖對沖網站**：建置 100% 地端運行的互動式 Web 儀表板，提供全球總經脈絡、當日選股當沖可行性評估（+2.5% 停利 / -1.5% 停損）、歷次選股與持股當下出場雷達（🚨 緊急停損、🎯 達標停利、⏰ 到期結算、⚠️ 破線減碼）。

## 主要功能與系統模組

### 1. 全球市場與個人部位晨間報告
- **全球投資市場研究報告_YYYY-MM-DD.pdf**：2 頁視覺化分析（涵蓋 11 大指數、總經指標、即時新聞焦點、三大法人買賣超、今日衛星選股與近 20 交易日滾動追蹤）。
- **個人投資部位分析報告_YYYY-MM-DD.pdf**：2 頁 Dashboard（最新市值、總資產、核心/衛星比重、個股損益、8% 年化目標檢核與操作建議）。

### 2. 地端即時監控與當沖對沖決策儀表板 (`http://127.0.0.1:8888`)
- **啟動方式**：雙擊根目錄下的 [`啟動在地即時監控儀表板.bat`](file:///C:/Users/User/Desktop/股市/啟動在地即時監控儀表板.bat) 即可自動開啟。
- **三大即時面板**：
  1. 🌐 **全球市場與總經脈絡**：即時行情、VIX、公債殖利率、美元指數與市場情緒燈號。
  2. ⚡ **當日選股當沖對沖決策**：自動評估晨間選股之開盤位階與量比，給出「🟢 多方當沖」、「🔴 避開/反向避險」訊號，提供 +2.5% 停利 / -1.5% 停損價與 13:00 強制平倉提醒。
  3. 🎯 **歷次選股當下出場雷達**：盤中即時追蹤未停損活躍標的（落實「只要建議過立即停損，則隔日就不再繼續追蹤」之剛性紀律），提供「🚨 立即停損出場」、「🎯 達標分批停利」、「⏰ 到期結算換股」、「⚠️ 破線減碼防守」、「🛡️ 均線軌道續抱」決策。

### 3. 量化策略治理與每季定期檢核機制
- **檢核週期**：每季（約 90 天 / 1 季 / 3 個月）定期執行全盤策略檢核與模型覆盤。
- **治理檔案**：[`config/strategy_adjustments.json`](file:///C:/Users/User/Desktop/股市/config/strategy_adjustments.json)（上次檢視日：2026-10-25，下次應檢核日：2027-01-25）。
- **覆盤範圍**：學術 10 指標權重分配、風控懲罰扣分項、波段/短衝停利停損門檻、跨期勝率矩陣與同月份效應成效；若需調整將出具獨立《策略模型調整與回測報告》。

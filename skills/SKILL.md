# 金融股市分析與投資組合評估技能指南 (SKILL.md)

本技能適用於執行全球大盤分析、台股與美股個股數據抓取、個人投資持股動態計價、8% 年化報酬目標檢核與視覺化 Dashboard PDF 報告生成。

## 技能應用場景

1. **數據抓取與更新**：
   - 抓取 TWSE 每日上市股票收盤行情 (MI_INDEX) 與三大法人買賣超 (T86)。
   - 抓取 Yahoo Finance 11 大全球股市指數、匯率、VIX、公債殖利率、商品行情。
   - 抓取鉅亨網 (Anue API) 及財經新聞 RSS 焦點新聞標題與摘要。

2. **持股動態計價與績效分析**：
   - 解析 [DP.csv](file:///C:/Users/User/Desktop/股市/投資部位/DP.csv) 與 [IP.csv](file:///C:/Users/User/Desktop/股市/投資部位/IP.csv)。
   - 以市場最新價位動態計算庫存現值、總資產、未實現損益、報酬率及核心/衛星配置比例。

3. **8% 年化報酬目標檢核與策略調整**：
   - 資產類別預期報酬假設：現金 (1%)、債券 (3.5%)、高股息 (6.5%)、大盤核心 (8%)、半導體/QQQ (10%)、衛星股 (9%)。
   - 檢視總資產預期報酬率與 8% 目標差距，提供現金配置與核心 ETF 補強建議。

4. **報告產製與排程**：
   - 產製 2 頁全彩 [全球投資市場研究報告](file:///C:/Users/User/Desktop/股市/全球投資市場研究報告_2026-07-21.pdf)。
   - 產製 2 頁全彩 [個人投資部位分析報告](file:///C:/Users/User/Desktop/股市/個人投資部位分析報告_2026-07-21.pdf)。
